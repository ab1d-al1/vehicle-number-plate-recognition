# Demo Examples

This directory contains demonstration materials for the Vehicle Number Plate Detection and Recognition project.

## Image Source

All demonstration images added here are independently obtained or captured images that we have permission to publish.

No UFPR-ALPR dataset images or annotations are included.

## Purpose

The examples demonstrate:

- Vehicle image input
- License plate detection
- Bounding-box localization
- Number plate text recognition
- Model output visualization

## Privacy

Use only images that are legally permitted for public demonstration.
Avoid publishing identifiable vehicle information without appropriate authorization.
